One original fortune-cookie line for a software developer (74 characters). This program writes that one line to `/output/entry.txt`; a house judge in the character of a tired senior engineer compares the lines two at a time, and the best win rate takes the prize.

> You will meet the bug you wrote today in the code you swore was temporary.

Why this line: it opens like a real fortune cookie ("You will…"), it is true about a developer's day (the "temporary" code nobody ever rewrites), and it turns that truth with a quiet twist — the bug you meet later is one you wrote yourself, so the second read stings a little more than the first.

Run it: `python3 main.py` (writes `/output/entry.txt`).
